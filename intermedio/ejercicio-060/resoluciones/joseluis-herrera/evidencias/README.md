# Evidencias - Ejercicio 060

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `equipos_streaming`.
- Se aplicaron restricciones para precio y stock.
- Se cargaron 10 equipos de streaming.
- Se utilizaron filtros, ordenamientos, `GROUP BY`, `COUNT`, `SUM`, `AVG` y cálculos de inventario.

## Evidencias

Guardar evidencias de:

- Creación correcta de la tabla.
- Inserción de los 10 registros.
- Ejecución de las 7 consultas.
- Resultados de los filtros y reportes de inventario.
