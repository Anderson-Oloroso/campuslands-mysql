# Descripcion 
Este proyecto incluye la creación, población y consulta de una base de datos relacional orientada al análisis de métricas básicas de uso en una plataforma de música (usuarios, playlists y canciones).

## Consutas creadas 
1. Muestra la métrica acumulada de cada usuario registrado en la plataforma, calculando el volumen de contenido creado y la duración total de sus reproducciones.
2. Analiza cada lista de reproducción de forma individual, cruzando la información con su creador y calculando métricas de rendimiento interno por pista.
