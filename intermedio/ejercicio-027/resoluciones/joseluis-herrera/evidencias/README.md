# Ejercicio 027 - Consultas de reportes para videojuego de acción y aventura

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Base de datos `campuslands_mysql`.
- Tabla `jugadores`.
- Restricciones `PRIMARY KEY`, `NOT NULL`, `ENUM` y `CHECK`.
- 10 registros de prueba.
- Reportes con `COUNT`, `SUM`, `AVG`, `GROUP BY`, `ORDER BY`, `LIMIT` y subconsultas.
