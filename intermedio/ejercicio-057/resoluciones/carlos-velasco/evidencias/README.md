# Evidencias - Ejercicio 057

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Evidencias

- Creación correcta de la tabla `personajes`.
- Inserción de 12 registros.
- Reporte de personajes activos.
- Conteo y estadísticas agrupadas por clase.
- Reporte utilizando `HAVING`.
- Top 5 por experiencia.
- Reporte de personajes con alto poder de ataque.
- Resumen general de personajes activos.

## Validaciones

Las consultas utilizan alias claros, filtros, ordenamientos, funciones de agregación, `GROUP BY`, `HAVING` y `LIMIT` para generar reportes verificables.
