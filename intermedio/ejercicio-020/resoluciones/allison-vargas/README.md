## Conceptos Aplicados
* **Subconsultas Escalares**: Comparación directa con funciones de agregación globales (e.g., AVG(), SUM()).
* **Subconsultas de Lista (IN) y Correlacionadas (EXISTS / NOT EXISTS)**: Filtrado entre tablas relacionadas.
* **Tablas Derivadas (FROM (SELECT ...))**: Tratamiento de resultados agrupados como tablas temporales para análisis extendidos.

## Estructura de Ejecución
1. ddl/schema.sql: Creación de tablas base.
2. dml/inserts.sql: Carga de datos iniciales.
3. dql/consultas.sql: 5 consultas analíticas basadas en subconsultas.
