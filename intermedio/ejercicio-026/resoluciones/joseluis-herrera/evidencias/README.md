# Ejercicio 026 - CHECK para videojuego RPG

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Base de datos `campuslands_mysql`.
- Tabla `personajes_rpg`.
- Restricciones `CHECK` para nivel, vida, mana y oro.
- 10 registros de prueba.
- Consultas con `WHERE`, `COUNT`, `AVG`, `GROUP BY`, `ORDER BY` y `LIMIT`.
