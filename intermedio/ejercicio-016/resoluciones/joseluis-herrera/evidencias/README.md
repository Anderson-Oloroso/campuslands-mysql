# Ejercicio 016 - INNER JOIN para restaurante de comida urbana

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se crearon las tablas `clientes`, `platos`, `pedidos` y `detalle_pedido`.
- Se utilizaron claves primarias, claves foráneas, `NOT NULL` y restricciones `CHECK`.
- Se insertaron datos suficientes para probar las relaciones entre las tablas.
- Se utilizaron `INNER JOIN`, filtros, `GROUP BY`, agregaciones, ordenamientos y cálculos de totales.
