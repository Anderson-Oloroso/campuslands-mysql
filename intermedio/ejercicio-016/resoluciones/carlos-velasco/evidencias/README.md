# Ejercicio 016 - INNER JOIN para restaurante de comida urbana

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se crearon las tablas `clientes`, `platos` y `pedidos`.
- Se utilizaron claves primarias, claves foráneas, `UNIQUE` y `CHECK`.
- Se insertaron 8 clientes, 10 platos y 12 pedidos.
- Las consultas utilizan `INNER JOIN`, filtros, agrupaciones, cálculos, ordenamientos y agregaciones.
