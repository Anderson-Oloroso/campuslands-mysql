# Ejercicio 046 - INNER JOIN para restaurante de comida urbana

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se crearon las tablas `clientes`, `productos`, `pedidos` y `detalle_pedido`.
- Se utilizaron `PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `ENUM` y `CHECK`.
- Se insertaron 8 clientes, 8 productos, 8 pedidos y 14 detalles.
- Se utilizaron `INNER JOIN`, `GROUP BY`, `SUM`, `COUNT`, `WHERE` y `ORDER BY`.
