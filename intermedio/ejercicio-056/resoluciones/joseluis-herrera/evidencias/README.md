## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `personajes_rpg`.
- Se aplicaron restricciones `CHECK` para nivel, vida, oro y estado.
- Se insertaron 10 registros coherentes.
- Se utilizaron `WHERE`, `GROUP BY`, `COUNT`, `AVG`, `SUM` y `ORDER BY`.
