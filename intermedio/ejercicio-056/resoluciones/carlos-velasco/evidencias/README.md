# Evidencias - Ejercicio 056

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Evidencias

- Creación correcta de la tabla `personajes_rpg`.
- Inserción de 10 registros.
- Resultados de las consultas de filtros y ordenamiento.
- Conteo de personajes por clase.
- Nivel promedio por clase.
- Ranking de experiencia.
- Estadísticas generales.

## Validaciones

La tabla utiliza restricciones `CHECK` para controlar el nivel, puntos de vida, puntos de maná, experiencia y estado de los personajes.
