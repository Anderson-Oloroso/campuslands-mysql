# Evidencias - Ejercicio 059

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `productos_accesorios`.
- Se aplicaron restricciones para precio y stock.
- Se insertaron 10 productos de diferentes categorías y estados.
- Se crearon las vistas `vista_productos_activos` y `vista_productos_por_categoria`.
- Se utilizaron filtros, ordenamientos, agregaciones y consultas sobre vistas.

## Evidencias

Guardar evidencias de:

- Creación de la tabla y las vistas.
- Inserción de los 10 registros.
- Ejecución de las 6 consultas.
- Resultados de las vistas y reportes por categoría.
