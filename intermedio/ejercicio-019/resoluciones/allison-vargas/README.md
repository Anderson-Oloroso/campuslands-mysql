## Conceptos Aplicados
* **Filtrado de Grupos (HAVING)**: Evaluación de restricciones sobre agregaciones como SUM(monto_usd), AVG(altura_pies) y COUNT(*).
* **Diferenciación entre WHERE y HAVING**: Uso de WHERE para filtrar registros individuales (ej. estado de salto) y HAVING para métricas consolidadas.

## Estructura de Ejecución
1. ddl/schema.sql: Creación de la tabla saltos_having.
2. dml/inserts.sql: Carga de 9 registros de saltos.
3. dql/consultas.sql: 5 consultas analíticas estructuradas con GROUP BY y HAVING.
