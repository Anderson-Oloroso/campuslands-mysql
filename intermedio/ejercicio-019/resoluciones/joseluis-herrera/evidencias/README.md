# Ejercicio 019 - HAVING para paracaidismo

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `saltos`.
- Se aplicaron `PRIMARY KEY`, `NOT NULL`, `DEFAULT` y restricciones `CHECK`.
- Se insertaron 12 registros.
- Se utilizaron `GROUP BY`, `HAVING`, `COUNT`, `AVG`, `SUM` y `MAX`.
- Las consultas filtran grupos según cantidades, precios e ingresos.
