# Ejercicio 008 - Normalización 3FN (Fútbol Sala)

## Autor
Sergio Ajú

## Descripción
Solución estructurada en Tercera Forma Normal (3FN) para la gestión de un torneo de fútbol sala, controlando equipos, jugadores y estadísticas de rendimiento.

## Orden de ejecución en MySQL Workbench
1. Ejecutar el script `ddl/schema.sql` para crear la base de datos y sus tablas relacionadas mediante llaves foráneas.
2. Ejecutar el script `dml/inserts.sql` para poblar los registros iniciales.
3. Ejecutar el script `dql/consultas.sql` para verificar los reportes, filtros y rankings de los jugadores.
