# Ejercicio 049 - HAVING para paracaidismo

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `saltos`.
- Se aplicaron `PRIMARY KEY`, `AUTO_INCREMENT`, `NOT NULL`, `CHECK` y `ENUM`.
- Se insertaron 10 registros de saltos.
- Se utilizaron `GROUP BY`, `HAVING`, `COUNT`, `AVG`, `SUM`, `MAX` y `MIN`.
