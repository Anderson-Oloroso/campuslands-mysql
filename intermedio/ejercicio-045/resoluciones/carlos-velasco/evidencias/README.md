# Ejercicio 045 - carga de datos para biblioteca gamer

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `videojuegos`.
- Se aplicaron restricciones `NOT NULL`, `CHECK` y `ENUM`.
- Se insertaron 10 registros.
- Se utilizaron filtros, ordenamientos, `GROUP BY`, `COUNT`, `AVG` y `LIMIT`.
- Los datos incluyen diferentes géneros, plataformas y estados para validar las consultas.
