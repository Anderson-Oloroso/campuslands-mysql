# Ejercicio 015 - Carga de datos para biblioteca gamer

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `videojuegos`.
- Se aplicaron `PRIMARY KEY`, `ENUM` y validaciones para precio y puntaje.
- Se cargaron 10 registros variados y coherentes.
- Se utilizaron filtros, ordenamientos, `GROUP BY`, `COUNT`, `AVG` y `LIMIT`.
