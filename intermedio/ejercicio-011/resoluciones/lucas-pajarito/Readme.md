## Descripcion de lo elaborado.

En la elaboracion de este readme se ha utilizado la plantilla asignada en la cual se han agregado validaciones de `Check` para una validación y que el puntaje no sea negativo.


Ejemplo 

```sql
        punteo int CHECK(punteo => 0)

        -- En este caso estamos validando que el punteo no ingrese uun valor menos de 0,
```
