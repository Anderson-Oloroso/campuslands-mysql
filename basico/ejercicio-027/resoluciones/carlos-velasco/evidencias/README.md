# Ejercicio 027 - Modelado de entidad para videojuego de accion y aventura

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la entidad `personajes_aventura`.
- Se utilizaron `PRIMARY KEY`, `NOT NULL`, `UNSIGNED`, `ENUM` y restricciones `CHECK`.
- Se insertaron 10 personajes con diferentes atributos y estados.
- Se utilizaron `WHERE`, `ORDER BY`, `LIMIT`, `COUNT`, `AVG` y `GROUP BY`.git
