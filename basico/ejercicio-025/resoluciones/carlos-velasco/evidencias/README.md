# Ejercicio 025 - COUNT y SUM para laboratorio de formulas quimicas

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `formulas_quimicas`.
- Se utilizaron `NOT NULL`, `ENUM` y restricciones `CHECK`.
- Se insertaron 10 registros coherentes.
- Se utilizaron `COUNT`, `SUM`, `WHERE`, `GROUP BY` y `ORDER BY`.
- Las consultas permiten obtener cantidades de formulas y muestras generales, por categoría y por estado.
