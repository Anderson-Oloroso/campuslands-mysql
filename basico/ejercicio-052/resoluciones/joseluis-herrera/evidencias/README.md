# Ejercicio 052 - ORDER BY para animacion 3D

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `proyectos_3d` con restricciones para duración, presupuesto y estado.
- Se insertaron 10 registros con diferentes proyectos, artistas, presupuestos y estados.
- Se utilizaron `ORDER BY` ascendente y descendente, ordenamiento múltiple, `GROUP BY` y `LIMIT`.
