# Ejercicio 052 - ORDER BY para animacion 3D

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `proyectos_animacion`.
- Se aplicaron `PRIMARY KEY`, `UNIQUE`, `NOT NULL` y restricciones `CHECK`.
- Se insertaron 10 proyectos con diferentes tipos de animación, presupuestos, horas, fechas y estados.
- Las consultas practican ordenamientos ascendentes, descendentes, múltiples, filtros y Top 5 mediante `ORDER BY` y `LIMIT`.
