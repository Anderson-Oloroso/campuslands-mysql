# Ejercicio 016 - CREATE TABLE para restaurante de comida urbana

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `platos` con información de los productos del restaurante.
- Se utilizó `PRIMARY KEY`, `AUTO_INCREMENT`, `NOT NULL`, `DEFAULT` y `CHECK` para validar los datos.
- Se insertaron 10 registros para probar diferentes casos.
- Se utilizaron filtros, ordenamientos, agregaciones, `GROUP BY` y `LIMIT`.
