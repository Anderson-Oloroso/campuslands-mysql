# Ejercicio 016 - CREATE TABLE para restaurante de comida urbana

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `platos`.
- Se aplicaron `PRIMARY KEY`, `UNIQUE`, `NOT NULL` y `CHECK`.
- Se insertaron 10 platos de diferentes categorías y precios.
- Las consultas utilizan filtros, ordenamientos, agrupaciones, `COUNT()`, `AVG()` y `LIMIT`.
