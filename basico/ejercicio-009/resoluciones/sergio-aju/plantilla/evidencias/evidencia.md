# Ejercicio 009: DELETE Controlado para Kickboxing

## Descripción
Solución en MySQL para practicar la sentencia `DELETE` controlada en una base de datos de kickboxing.

## Instrucciones de Ejecución
Ejecuta los scripts en orden:
1. `mysql -u root -p < ddl/schema.sql`
2. `mysql -u root -p < dml/inserts.sql`
3. `mysql -u root -p < dql/consultas.sql`
