# Resolución Ejercicio 007 (Básico) - ORDER BY Liga de Fútbol

**Estudiante:** Allison Vargas  
**Nivel:** Básico Inicial  

## Descripción
Uso de la cláusula ORDER BY en MySQL para la ordenación de tablas de posiciones, rankings defensivos/ofensivos y ordenamiento alfabético compuesto.

## Estructura de Ejecución
1. ddl/schema.sql: Creación de la base de datos campuslands_mysql y tabla equipos_liga_basico.
2. dml/inserts.sql: Carga de 8 equipos con estadísticas completas de puntos y goles.
3. dql/consultas.sql: 5 consultas aplicando criterios de ordenamiento ascendente (ASC), descendente (DESC) y calculados.
