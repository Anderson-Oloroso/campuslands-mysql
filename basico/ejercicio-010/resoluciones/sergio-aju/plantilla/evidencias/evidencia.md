# Ejercicio 010: COUNT y SUM para Carreras Urbanas

## Descripción
Solución en MySQL enfocada en el uso de funciones de agregación `COUNT` y `SUM` para analizar inscripciones y recaudaciones en carreras urbanas.

## Instrucciones de Ejecución
Ejecuta los scripts en orden:
1. `mysql -u root -p < ddl/schema.sql`
2. `mysql -u root -p < dml/inserts.sql`
3. `mysql -u root -p < dql/consultas.sql`
