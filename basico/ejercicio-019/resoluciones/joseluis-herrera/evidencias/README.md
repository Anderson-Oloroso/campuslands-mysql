# Ejercicio 019 - INSERT para paracaidismo

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `saltos`.
- Se utilizaron `PRIMARY KEY`, `NOT NULL`, `DEFAULT` y restricciones `CHECK`.
- Se insertaron 10 registros.
- Se utilizaron filtros, ordenamientos, `AVG`, `COUNT`, `GROUP BY` y `LIMIT`.
