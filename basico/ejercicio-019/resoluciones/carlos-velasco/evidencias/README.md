# Ejercicio 019 - INSERT para paracaidismo

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `saltos`.
- Se aplicaron `PRIMARY KEY`, `AUTO_INCREMENT`, `NOT NULL`, `ENUM` y restricciones `CHECK`.
- Se insertaron 10 registros de participantes y saltos.
- Las consultas utilizan filtros, ordenamientos, cálculos, agregaciones, `GROUP BY` y `LIMIT`.
