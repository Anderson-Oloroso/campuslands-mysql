# Ejercicio 048 - PRIMARY KEY para viajes y turismo

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `destinos`.
- Se utilizó `PRIMARY KEY` con `AUTO_INCREMENT`.
- Se aplicaron `NOT NULL`, `CHECK` y `ENUM`.
- Se insertaron 10 destinos turísticos.
- Se utilizaron filtros, ordenamientos, agrupaciones y `LIMIT`.
