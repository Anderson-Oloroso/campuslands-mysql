# Ejercicio 017 - Tipos de datos para tienda de ropa

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `prendas` con tipos `INT`, `VARCHAR`, `DECIMAL`, `DATE`, `ENUM` y `BOOLEAN`.
- Se aplicaron restricciones `NOT NULL`, `PRIMARY KEY`, `CHECK` y `DEFAULT`.
- Se insertaron 10 registros coherentes con la temática.
- Se utilizaron filtros, ordenamientos, cálculos, `GROUP BY`, agregaciones y `LIMIT`.
- Se incluyeron consultas para disponibilidad, stock, precios, valor del inventario y Top 5.
