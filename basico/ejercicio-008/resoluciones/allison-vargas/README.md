## Descripción
Uso de la sentencia UPDATE en MySQL para la actualización condicional de estados, capitanes, goles acumulados y puntajes de tabla en fútbol sala.

## Estructura de Ejecución
1. ddl/schema.sql: Creación de la base de datos campuslands_mysql y tabla equipos_futsal_basico.
2. dml/inserts.sql: Carga de 8 equipos y aplicación de sentencias UPDATE condicionales.
3. dql/consultas.sql: 5 consultas de verificación de estado post-actualización y estadísticas.
