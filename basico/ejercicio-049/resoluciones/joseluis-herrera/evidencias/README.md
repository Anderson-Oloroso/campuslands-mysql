# Ejercicio 049 - INSERT para paracaidismo

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `saltos`.
- Se aplicaron `PRIMARY KEY`, `AUTO_INCREMENT`, `CHECK` y `ENUM`.
- Se insertaron 10 registros realistas de reservas y saltos.
- Se utilizaron filtros, agrupaciones, ordenamientos y `LIMIT`.
