# Ejercicio 034 - INSERT para garaje de motos

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `motos` con 10 registros.
- Se utilizaron `PRIMARY KEY`, `NOT NULL`, `CHECK`, `ENUM` y `UNIQUE`.
- Se practicó `INSERT` con datos realistas de motos.
- Se incluyeron consultas con filtros, `ORDER BY`, `LIMIT`, `COUNT`, `AVG` y `SUM`.
