# Ejercicio 035 - SELECT para taller mecanico de motos

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `servicios_mecanicos`.
- Se insertaron 10 registros con diferentes servicios, costos y estados.
- Se utilizó `PRIMARY KEY`, `NOT NULL`, `ENUM` y `CHECK`.
- Se practicó `SELECT` con filtros, `ORDER BY`, `IN`, `LIMIT`, `COUNT`, `SUM` y `AVG`.
