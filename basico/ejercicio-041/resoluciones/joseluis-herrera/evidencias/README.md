# Ejercicio 041 - Validaciones simples para pingpong

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

* Se utilizó la base de datos `campuslands_mysql`.
* Se creó la tabla `jugadores`.
* Se aplicaron `NOT NULL`, `CHECK`, `ENUM` y `UNIQUE`.
* Se insertaron 8 jugadores con diferentes categorías y estados.
* Se utilizaron filtros, ordenamientos, `COUNT`, `SUM`, `AVG` y `GROUP BY`.
