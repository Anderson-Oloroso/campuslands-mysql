# Ejercicio 022 - ORDER BY para animacion 3D

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `proyectos_animacion`.
- Se utilizaron `PRIMARY KEY`, `NOT NULL`, `ENUM` y restricciones `CHECK`.
- Se insertaron 10 registros.
- Se utilizaron `ORDER BY`, `WHERE`, `GROUP BY`, `AVG`, `COUNT` y `LIMIT`.
- Se realizaron ordenamientos ascendentes, descendentes y múltiples.
