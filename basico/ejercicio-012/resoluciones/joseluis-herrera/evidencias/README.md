# Descripcion 
En este ejercicio se realizo una base de datos para una playlist de musica en la cual se contienen tablas como 
usuarios, playlist, canciones

## Consultas Incluidas
Consulta 1: Listado de todas las playlists públicas junto con el nombre del usuario propietario.

Consulta 2: Conteo total de canciones y suma de duración en segundos por cada playlist mediante LEFT JOIN y GROUP BY.

Consulta 3: Canción con mayor duración registrada en la base de datos, incluyendo el nombre de la playlist a la que pertenece.
