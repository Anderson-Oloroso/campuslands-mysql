# Ejercicio 033 - PRIMARY KEY para inventario de skins shooter

## Descripción

Solución del ejercicio de MySQL enfocado en el uso de PRIMARY KEY mediante un inventario de skins de un videojuego shooter.

La tabla principal permite identificar de forma única cada skin y almacenar información relacionada con arma, rareza, precio, fecha de adquisición y estado de equipamiento.
