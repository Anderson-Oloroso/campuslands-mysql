# Ejercicio 047 - Tipos de datos para tienda de ropa

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `prendas`.
- Se utilizaron `INT`, `VARCHAR`, `DECIMAL`, `BOOLEAN`, `DATE`, `DATETIME` y `TEXT`.
- Se aplicaron restricciones `PRIMARY KEY`, `NOT NULL` y `CHECK`.
- Se insertaron 10 registros con diferentes categorías, tallas, precios y niveles de stock.
- Se utilizaron filtros, ordenamientos, agrupaciones, cálculos y `LIMIT`.
