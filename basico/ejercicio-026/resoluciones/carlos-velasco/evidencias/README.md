# Ejercicio 026 - Validaciones simples para videojuego RPG

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `personajes_rpg`.
- Se utilizaron `NOT NULL`, `UNSIGNED`, `ENUM` y restricciones `CHECK`.
- Se insertaron 10 personajes con diferentes clases, niveles y estados.
- Se utilizaron `WHERE`, `ORDER BY`, `LIMIT`, `COUNT`, `SUM` y `GROUP BY`.
