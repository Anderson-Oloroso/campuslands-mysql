# Ejercicio 028 - Filtros por estado para academia tech

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `estudiantes_academia`.
- Se utilizaron `PRIMARY KEY`, `UNIQUE`, `NOT NULL`, `ENUM` y `CHECK`.
- Se insertaron 10 estudiantes con estados `activo`, `inactivo` y `graduado`.
- Se utilizaron `WHERE`, `AND`, `ORDER BY`, `GROUP BY` y `COUNT`.
