# Evidencias - Ejercicio 059

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `productos_accesorios`.
- Se utilizaron columnas `DATE` para publicación y actualización.
- Se aplicaron restricciones para precio, stock y fechas.
- Se insertaron 10 productos.
- Se utilizaron filtros, ordenamientos, `DATEDIFF`, `YEAR`, `MONTH` y `GROUP BY`.

## Evidencias

Guardar evidencias de:

- Creación correcta de la tabla.
- Inserción de los 10 registros.
- Ejecución de las 6 consultas.
- Resultados de filtros y cálculos relacionados con fechas.
