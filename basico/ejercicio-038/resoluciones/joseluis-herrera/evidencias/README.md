# Ejercicio 038 - UPDATE para futbol sala

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `jugadores`.
- Se aplicaron restricciones `PRIMARY KEY` y `CHECK`.
- Se insertaron 10 registros.
- Se utilizaron `UPDATE` con condiciones mediante `WHERE`.
- Se realizaron modificaciones de estado, goles y equipo.
