# Ejercicio 042 - Modelado de entidad para playlist musical

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `canciones_playlist`.
- Se aplicaron `UNIQUE` y restricciones `CHECK` para validar los datos.
- Se agregaron 10 registros de canciones.
- Se utilizaron filtros, `ORDER BY`, `GROUP BY`, `COUNT`, `AVG` y `LIMIT`.
