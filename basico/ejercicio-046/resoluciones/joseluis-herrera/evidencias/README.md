# Ejercicio 046 - CREATE TABLE para restaurante de comida urbana

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `platos`.
- Se utilizaron `NOT NULL`, `CHECK`, `PRIMARY KEY`, `AUTO_INCREMENT` y `ENUM`.
- Se insertaron 10 registros con diferentes categorías, precios, calorías y estados.
- Se utilizaron filtros, ordenamientos, agrupaciones y cálculos mediante `COUNT` y `AVG`.
