# Ejercicio 046 - CREATE TABLE para restaurante de comida urbana

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `platos`.
- Se aplicaron restricciones `NOT NULL`, `PRIMARY KEY`, `DEFAULT` y `CHECK`.
- Se insertaron 10 registros.
- Se utilizaron filtros, `ORDER BY`, `GROUP BY`, `COUNT`, `AVG` y `LIMIT`.
