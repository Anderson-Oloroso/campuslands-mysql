1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `autos_hiperdeportivos` con restricciones para potencia, velocidad, precio, año y estado.
- Se insertaron 10 registros coherentes.
- Se utilizaron consultas `SELECT` con `WHERE`, comparaciones, `BETWEEN`, `AND` y `ORDER BY`.
