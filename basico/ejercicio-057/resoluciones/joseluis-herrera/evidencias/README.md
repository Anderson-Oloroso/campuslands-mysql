# Evidencias - Ejercicio 057

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la entidad `personajes_accion_aventura`.
- Se aplicaron restricciones para nivel, experiencia, monedas y salud.
- Se insertaron 10 personajes con diferentes clases, niveles y estados.
- Se utilizaron filtros, ordenamientos, `GROUP BY`, agregaciones, `LIMIT` y una subconsulta.

## Evidencias

Guardar evidencias de:

- Creación correcta de la tabla.
- Inserción de los 10 registros.
- Ejecución de las consultas.
- Resultados de los filtros, ranking, promedios y agrupaciones.
