# Evidencias - Ejercicio 057

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Evidencias

- Creación correcta de la tabla `personajes`.
- Inserción de 10 registros.
- Consulta de personajes activos.
- Consulta de personajes de nivel 50 o superior.
- Ranking de poder de ataque.
- Conteo de personajes por clase.
- Nivel promedio por clase.
- Estadísticas generales.

## Validaciones

La tabla utiliza una clave primaria y restricciones `CHECK` para controlar nivel, puntos de vida, poder de ataque, experiencia y estado.
