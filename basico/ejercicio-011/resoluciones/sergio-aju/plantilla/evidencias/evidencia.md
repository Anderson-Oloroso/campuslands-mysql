# Ejercicio 011: Validaciones simples para Ping Pong

## Descripción
Solución en MySQL aplicando validaciones simples y restricciones (`CHECK`) para un módulo de datos sobre tenis de mesa (ping pong).

## Instrucciones de Ejecución
Ejecuta los scripts en orden:
1. `mysql -u root -p < ddl/schema.sql`
2. `mysql -u root -p < dml/inserts.sql`
3. `mysql -u root -p < dql/consultas.sql`
