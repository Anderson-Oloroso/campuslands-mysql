# Explicacion 
En el este ejercicio se realizo el una base de datos para 
un juego de pig pog en el cual se hicieron 3 consultas utilizando validaciones simples.

## Consultas Incluidas
Consulta 1: Listado de jugadores de la categoría 'Sub-18' ordenados de mayor a menor según su puntaje de ranking.

Consulta 2: Total de partidos disputados por cada jugador registrado utilizando LEFT JOIN.

Consulta 3: Partido con el mayor total de puntos sumados entre ambos competidores.
