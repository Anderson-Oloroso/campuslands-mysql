# Ejercicio 052 - Vistas Avanzadas: Estudio de Animación 3D

## Descripción
Solución del ejercicio 052 para Campuslands. Se define e implementa la arquitectura relacional en MySQL orientada a la gestión de producción 3D, carga poligonal, motores de renderizado y control de presupuestos mediante **Vistas Avanzadas**.

## Estructura de Entregables
- `ddl/schema.sql`: Definición de tablas, llaves foráneas, checks y creación de vistas.
- `dml/inserts.sql`: Carga de datos de prueba.
- `dql/consultas.sql`: Consultas optimizadas sobre las vistas y tablas relacionales.
