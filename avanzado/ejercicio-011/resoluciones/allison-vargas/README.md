## Conceptos Aplicados
* **WITH (Common Table Expressions)**: Creación de subconsultas con nombre para modularizar y simplificar reportes complejos.
* **CTEs Múltiples y Combinadas**: Uso de uniones (UNION ALL) y agregaciones dentro de expresiones de tabla comunes para evaluar rendimiento y estadísticas.

## Estructura de Ejecución
1. ddl/schema.sql: Definición del esquema para jugadores y partidos de ping-pong.
2. dml/inserts.sql: Inserción de datos iniciales.
3. dql/consultas.sql: 5 consultas analíticas construidas con expresiones CTE.
