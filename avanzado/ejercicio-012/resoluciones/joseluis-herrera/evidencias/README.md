# Descripcion 
Documentación técnica de los cuatro ejercicios prácticos implementados para analizar datos con funciones de ventana (OVER, PARTITION BY, ORDER BY) 

# Consultas
1. Asigna un número consecutivo a cada canción dentro de su respectiva playlist según el orden en que fueron registradas.
2. Clasifica las canciones de cada lista en orden descendente según su duración en segundos.
