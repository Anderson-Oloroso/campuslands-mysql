**Estudiante:** Allison Vargas

## Conceptos Aplicados
* **MySQL Event Scheduler**: Configuración de SET GLOBAL event_scheduler = ON; y creación de eventos recurrentes (EVERY 1 HOUR, EVERY 1 DAY).
* **Automatización de Mantenimiento**: Actualización programada de niveles de energía y auditoría automática de naves con sobrecarga de horas de vuelo con registro en bitácora.

## Estructura de Ejecución
1. ddl/schema.sql: Creación de tablas y definición de eventos programados.
2. dml/inserts.sql: Carga de datos iniciales de naves espaciales.
3. dql/consultas.sql: Inspección del esquema de eventos y monitoreo de la flota.
