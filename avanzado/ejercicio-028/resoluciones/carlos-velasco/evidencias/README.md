# Evidencias - Ejercicio 028

## Ejecución

Guardar evidencias de:

1. Ejecución correcta de `ddl/schema.sql` y creación de `estudiantes`.
2. Ejecución de `dml/inserts.sql` con los 8 registros insertados.
3. Consulta de extracción de valores JSON.
4. Consulta de estudiantes filtrados por promedio.
5. Consulta de estudiantes que utilizan MySQL.
6. Consulta de conteo de tecnologías.
7. Consultas de agregación y agrupación sobre información JSON.

## Resultados importantes

Las evidencias deben demostrar que los datos JSON pueden ser almacenados, extraídos, filtrados y utilizados en cálculos y agrupaciones mediante funciones de MySQL.
