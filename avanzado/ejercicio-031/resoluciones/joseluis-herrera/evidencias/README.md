# Evidencias - Ejercicio 031

## Validaciones

- Captura de la ejecución correcta de `ddl/schema.sql`.
- Captura de la carga inicial de equipos y jugadores.
- Evidencia de una transacción confirmada mediante `COMMIT`.
- Evidencia de una transacción revertida mediante `ROLLBACK`.
- Evidencia de una transacción con múltiples operaciones.
- Evidencia de las consultas posteriores a las transacciones.
- Resultado final de jugadores por equipo.
