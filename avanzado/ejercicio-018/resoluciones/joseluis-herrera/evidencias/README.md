# Ejercicio 018 - Funciones SQL para viajes y turismo

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `destinos`.
- Se aplicaron `PRIMARY KEY`, `NOT NULL`, `DEFAULT` y `CHECK`.
- Se insertaron 10 destinos.
- Se utilizaron funciones de texto, agregación, fecha, redondeo, `COALESCE`, `CASE` y `LIMIT`.
