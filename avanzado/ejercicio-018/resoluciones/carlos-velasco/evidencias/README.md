# Ejercicio 018 - Funciones SQL para viajes y turismo

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se crearon las tablas `destinos`, `viajes` y `reservas`.
- Se utilizaron claves foráneas, `CHECK`, `ENUM` y `NOT NULL`.
- Se cargaron 10 destinos, 10 viajes y 10 reservas.
- Se implementaron 3 funciones para calcular duración, descuento y precio final.
- Se incluyeron 8 consultas con filtros, ordenamientos, cálculos, `JOIN`, `GROUP BY`, `HAVING` y ranking.
