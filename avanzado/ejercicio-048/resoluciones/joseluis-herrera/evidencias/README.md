# Ejercicio 048 - Funciones SQL para viajes y turismo

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `destinos`.
- Se aplicaron `PRIMARY KEY`, `AUTO_INCREMENT`, `NOT NULL`, `CHECK` y `ENUM`.
- Se insertaron 10 destinos turísticos.
- Se utilizaron funciones de texto, fecha, agregación y formato para generar reportes.
